NextGen Academy

NextGen Academy is an AI-powered learning platform that helps learners explore practical courses in Software Development, Data, Cloud, DevOps, Testing, and UI/UX.

✨ Features
🤖 AI-powered learning assistant
📚 Course catalog with learning paths
📝 Lead/contact submission
🔐 Admin login & lead management
📱 Responsive React interface
🎨 Tailwind CSS & Framer Motion
🗄️ MongoDB integration with demo-mode fallback
🛠️ Tech Stack

Frontend: React, Vite, Tailwind CSS, Framer Motion
Backend: Node.js, Express
Database: MongoDB, Mongoose
Authentication: JWT
Icons: Lucide React
